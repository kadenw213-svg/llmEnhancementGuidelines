**About**

This is a reusable prompt framework designed to make AI assistants more accurate, organized, and reliable 
during complex work. It helps the assistant slow down, check assumptions, ask for missing context
when needed, and avoid guessing when the task depends on important details.

The prompt is useful for coding, research, writing, planning, documentation, datasets, and other
multi-step projects where context matters. It gives the AI a clearer process for tracking goals,
confirmed facts, unresolved questions, constraints, active work, and next steps.

To use it, paste the full prompt at the start of a new AI chat, then explain the role you want the
assistant to take, the task you are working on, and any background context it needs. From there, the
assistant will follow the framework while helping you complete the task.

**Dependencies**
